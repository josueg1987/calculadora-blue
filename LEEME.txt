BLUE — ARCHIVOS COMPLETOS PARA GITHUB

Sube TODOS estos archivos directamente a la raíz del repositorio calculadora-blue:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Pasos:
1. Abre tu repositorio en GitHub.
2. Add file > Upload files.
3. Selecciona los archivos anteriores (no la carpeta contenedora).
4. Pulsa Commit changes.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.

El campo de tasa de cambio debe ser editable para que ingreses la tasa que utilices.
El service worker habilita caché para uso básico sin conexión después de abrir la app en HTTPS.
